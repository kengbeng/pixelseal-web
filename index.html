      About this prototype

      Files stay in this browser. No uploads, analytics or external assets. Export checks marked areas for remaining text and black fill; it is not a complete document security audit. Review the exported document before sharing.

      Forms and OCR are not supported. Scanned PDFs can be marked manually. Very large PDFs may exceed browser memory. Original files are never overwritten.

      Undo: Ctrl/Cmd+Z. Redo: Ctrl/Cmd+Shift+Z. Delete removes the selected area. Arrow keys move it by one point (Shift: ten).
