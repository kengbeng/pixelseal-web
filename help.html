PixelSeal user guide

For PixelSeal Web 0.5.2

Find sensitive content, mark the areas to remove, then review and download a redacted PDF. Files are processed in your browser.

Marks are pending until export. Text can remain readable under boxes in the editing view. Use Review & export to apply redactions, check the saved copy, and download it. Keep the original separately.

Quick start

  1. Select Open PDF and choose your file. Enter its password if prompted.
  2. In Find, enter a word or phrase and select Find. Leave Include scanned text checked if the file contains scanned pages.
  3. Review the results. Select a result to locate it on the page; use its checkbox to select it for marking.
  4. Select Mark selected (N). For content missed by search, switch to Mark, choose Draw, and drag a box around it.
  5. Select Review & export. Inspect the actual redacted output, including pages without marks.
  6. Select Download PDF. Share the downloaded file ending in -redacted.pdf after checking it.

Open and unlock a PDF

Select Open PDF, or Open a PDF in the empty workspace. Once loaded, the filename and Change PDF appear in the tools panel.

For a password-protected file, enter a valid document password and select Unlock PDF. Use Show password if needed. An incorrect password can be retried; Cancel stops opening the file.

Exported copies are unencrypted. The source password is used in memory for the current file. PixelSeal does not add a password to the downloaded PDF.

Opening another PDF replaces the current document, marks, search results and undo history. There is no saved editing session. Download your redacted copy before changing files or closing the app.

Find text and patterns

Choose a search type, then select Find. Settings collapse when the search finishes. Expand Search settings to change the query or scan options.

Search types
TypeUse
Word or phraseEnter a name, identifier or phrase. PDF text matching ignores letter case. Matches may occur within a longer word.
Email addressesSuggest email-like strings without entering a query.
Phone numbersSuggest phone-like strings. Numbers such as identifiers can also match.
Custom patternUse # for a digit, @ for an English letter and ? for a non-space character. For example, ID-#### finds ID-1234. Use a backslash before a token to match it literally, such as \#. Patterns are limited to 120 characters; regular expressions are not supported.

Results are grouped by page. Each result shows nearby text where available and a PDF text or OCR badge. Select the result text to locate and highlight the area. This does not check its selection box.

  • Check individual results, or use a page checkbox to select that page’s matches.
  • Select current matches selects the results available at that moment. New OCR results are not selected automatically.
  • Deselect all clears the selection without removing existing marks.
  • Mark selected (N) adds areas for the selected matches. A phrase may create more than one area.
  • A Marked badge identifies a result already covered by its original search boxes. Visually recheck results if you move or resize their marks.

Patterns and OCR provide suggestions. They can miss sensitive content or identify content that should remain. Review before marking. If the app reports the 500-match per-page limit, narrow the query and repeat the search.

Search scanned pages with OCR

Include scanned text is enabled by default. Find returns selectable PDF text first, then recognises scanned pages locally. Results arrive page by page. Wait for completion or note the incomplete-search warning before exporting.

Expand Search settings → Scan options to choose:

Scan scope
OptionPages recognised
Current pageOnly the page currently displayed. PDF text search still covers the document.
Pages without selectable textThe default. Pages with no extracted PDF text.
Scan all pages (including mixed pages)All pages, including those containing both selectable text and scanned images.

Choose English or Chinese (simplified). If a scan is sideways or upside down, choose the OCR rotation needed to make its text upright. Rotation changes recognition only; the original page orientation remains unchanged.

Scan selected pages recognises the chosen scope again and clears the current match list. After scanning, enter a query and use Find to search the recognised text. Completed scans are reused for the same language and rotation while the document remains open.

An OCR percentage is the recognition engine’s confidence, not a guarantee that the text or box is correct. Matches below 70% show a low-confidence warning. Inspect every OCR box against the page image; a match may cover a whole recognised word even when only part of it matches the query.

Cancel scan retains results from completed pages. The search remains incomplete. Run Find again with the same settings to reuse completed scans and process remaining pages in the selected scope. Use Scan all pages if image text on a mixed page was missed.

OCR supports finding redactions. It does not add a searchable text layer to the exported PDF.

Draw and edit areas

  1. Switch to Mark and choose Draw.
  2. Drag over content to create an area. Cover all content that must be removed while checking adjacent text and graphics.
  3. Select a box to move it, or drag a corner handle to resize it.
  4. For numerical control, select an area and expand Precise coordinates. Set X, Y, Width and Height, then select Apply dimensions. Values are PDF points, not screen pixels. Keep the area within the page.

Add area without dragging creates a centred box on the current page. Select its entry in Marked areas to navigate to it and edit its dimensions. Manual boxes must be at least 5 PDF points wide and tall.

Remove deletes an individual mark. Clear all removes all marks. Undo and Redo restore marking changes, including batch additions. Search and file-opening operations are not part of the marking undo history.

Use Pan to scroll or swipe the page without drawing. Return to Draw to select, move or resize boxes. Zoom changes the view, not the area’s PDF coordinates.

Review, verify and download

Review & export becomes available when at least one area is marked and scanning has stopped. PixelSeal applies the redactions and checks the generated PDF before opening the output preview.

  1. Use the arrows or page thumbnails to inspect the output. Use Fit page, Fit width or a numeric zoom for closer review.
  2. Use Marked area to jump to each redaction. Amber outlines are review guides; they are not saved in the PDF.
  3. Check I have reviewed this exported page after inspecting a page. The count tracks your confirmations for this preview. It does not block download and resets when the preview closes or a new export is prepared.
  4. Open the verification summary to read what was checked. If search was incomplete, review that warning and consider returning to complete the search.
  5. Select Download PDF. The filename ends in -redacted.pdf. Use Back to editing if changes are needed, then prepare a fresh export.
What verification means: PixelSeal checks for remaining PDF text and black fill inside marked areas. It does not check that you found every sensitive item, or verify OCR accuracy. Review every page before sharing.

Redaction removes text, image pixels and line art touched by the marked regions. The output is rebuilt without source document metadata, attachments and page annotations such as comments. Review surrounding content because intersecting graphics or text may also be affected. Interactive PDF forms are not supported. The output is unencrypted and the original file is not overwritten.

Navigation and mobile use

Use the page arrows or Pages thumbnail rail to navigate. Thumbnails show the number of marked areas. Fit page shows the full page; Fit width makes it easier to read at the available width.

On smaller screens, Find opens the tools sheet. Locating a match closes the sheet and shows the matching page. Use Mark to draw, or Areas to open the marked-area list and precise controls. The selection action stays at the bottom of the Find sheet.

Use Pan when swiping a zoomed page. To change the document, open Find or Areas and use Change PDF. Help opens over the current view; closing it returns to your work.

Install, update and work offline

  1. Open PixelSeal while online. The first visit downloads the app, guide and English/Chinese OCR files, about 41 MB.
  2. Wait for Ready offline. On a small screen, this label may be hidden; install controls become available after setup.
  3. Select Install app if supported. Otherwise use the browser menu. Safari offers Add to Dock on supported Macs, or Add to Home Screen on iPhone and iPad. Options vary by browser.
  4. Open the installed app or revisit the site in the same browser to work offline. Help is included in the offline files.

When Update app appears, finish and download your current work first. Updating reloads PixelSeal and clears the current PDF, marks and OCR results. Closing, refreshing or replacing the document also clears the session.

Offline availability depends on the browser retaining the app’s cached files. Clearing site data, private browsing or browser storage eviction can require another online visit. Installation does not save PDF editing sessions.

Troubleshooting

No matches, or scanned text is missing
Check the spelling and selected language. Enable Include scanned text. For mixed pages, choose Scan all pages; the default skips OCR on pages that already have selectable text. Try OCR rotation for sideways scans, or mark the area manually.
Search incomplete
The scan was cancelled, failed or reached a result limit. Completed-page results may remain, but they do not cover all content. Run Find again, change scan settings if needed, or narrow a query that reached the per-page limit.
Verification failed: text remains in a marked area
The output did not pass verification. Note the reported page and character, return to that page and inspect the mark and adjacent text at a larger zoom. Adjust or redraw the area, then export again. If it repeats, retain the original and report the message and steps through the project repository. Share a non-sensitive sample only if needed.
Verification failed: fill incomplete, or an area is too small
Inspect the reported area, keep it inside the page and redraw or enlarge it as needed. Export again. Do not rely on a failed output.
A match overlaps neighbouring glyphs ambiguously
Draw that redaction manually and inspect the exported copy for unintended removal of adjacent content.
Review & export is disabled
Add at least one marked area. Selecting search checkboxes alone is not enough; select Mark selected (N). Wait for scanning to finish or cancel it.
Interactive PDF forms are not supported
Prepare a flattened copy using a trusted PDF tool, then open that copy in PixelSeal. Check that the flattened version retains the required content.
Incorrect password
Use a valid password for the selected file. PixelSeal cannot recover an unknown password.
The app is slow or a preview fails
Large PDFs and high-resolution scans can exceed browser memory. Try a smaller document or current-page OCR. If you need to reload, download any available verified work first; unsaved marks will be lost.
The new version or Help is not appearing
Reopen the app while online and wait for offline files to finish downloading. Use Update app when offered. Save current work before refreshing or updating.

Privacy and limitations

  • PDF processing and OCR run locally. PixelSeal does not upload PDF bytes or use analytics. The host receives requests for application files when loading or updating the site.
  • The offline cache contains application assets and this guide, not your PDFs, passwords, marks or recognised text. Document data remains in memory for the active session.
  • Downloads are saved to the location managed by your browser. Protect downloaded copies and originals according to your needs.
  • Verification covers marked areas only. It is not a complete document security audit. Search, patterns and OCR cannot guarantee that every sensitive item is found.
  • The app supports English and simplified Chinese OCR. Handwriting, poor scans and unusual layouts may be recognised incorrectly.
  • The app does not save editing sessions, encrypt exports or add searchable OCR text. Interactive forms are not supported.

For project information, licensing and issue reporting, visit the PixelSeal source repository (opens in a new tab). Avoid posting private documents, passwords or sensitive text in public issues.
